## Visão Geral
Esse projeto tem como objetivo criar um sistema de trade financeiro chamado *Sentinel Trade*. O sistema será uma plataforma distribuída, segura, escalável e tolerante a falhas, que será capaz de fazer as seguintes coisas: permitir que os investidores acompanhem as cotações, mantenham uma carteira de ativos, enviem ordens de compra e venda e consultem o histórico de operações
